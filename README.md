# SistemaTicket

Sistema web de gestión de tickets desarrollado con:

- Python
- Flask
- SQL Server
- SQLAlchemy
- Flask Login

## Funcionalidades V1

- Login de usuarios
- Menú principal
- Creación de tickets
- Almacenamiento en SQL Server

## Tecnologías

- Python 3.11
- Flask
- SQL Server
- Bootstrap (futuro)
- Microsoft Entra ID (pendiente)

## Instalación

```bash
pip install -r requirements.txt
python app.py
